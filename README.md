### Pemasangan Config
- Wajib core **Clash Meta (mihomo)** di OpenClash.
- Upload `dudul.yaml` lewat Config Manage.
- Upload isi folder `proxy_provider` dan `rule_provider` ke folder yang sama di `/etc/openclash/` (pakai Config Editor / File Manager).
- Commit settings dan apply settings.

### Tambah atau Ganti Akun VPN
- Masuk Config Editor
- Cari direktori `proxy_provider`
- Edit file `proxy.yaml` (hapus akun contoh yang tidak dipakai)

Kalau OpenClash menimpa setting, aktifkan juga di LuCI → OpenClash → Overwrite Settings → Meta:
- **Unified Delay**: ON
- **TCP Concurrent**: ON
- Mode: **Fake-IP**
